## 📌 Overview

This repository serves as a **complete handbook and personal codebase** for mastering **Data Structures and Algorithms (DSA)** in **C++**, following the comprehensive curriculum aligned with industry standards (Coder Army / Rohit Negi Roadmap).

### 🎯 Key Highlights
- 🧩 **Zero to Advanced Coverage:** From basic loops and bit manipulation to advanced algorithms like KMP, Tarjan's, Segment Trees, and Multi-dimensional DP.
- 📂 **Modular & Systematic Organization:** Each topic is organized into granular, topic-labeled sub-folders for instant revision.
- ⚡ **Clean & Optimized Code:** Written with modern C++ standards, adhering to optimal time and space complexities.
- 💡 **Interview & LeetCode Centric:** Every section focuses on core patterns asked in Online Assessments (OAs) and Technical Rounds.

## 🛠️ How to Compile & Run

### Prerequisites
* **Compiler:** `g++` (GCC 10+ supporting C++17 or C++20)
* **IDE/Editor:** Visual Studio Code (with C/C++ and Code Runner extensions)

### Running via Terminal
```bash
# Compile any C++ file
g++ -std=c++17 -O2 filename.cpp -o filename

# Execute binary
./filename        # Linux / macOS
.\filename.exe    # Windows
```
